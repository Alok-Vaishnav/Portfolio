# Alok Vaishnav — Portfolio

Personal portfolio built with Next.js, Framer Motion, and SCSS. Showcases projects, skills, and contact links with smooth scroll and hover effects.

## Tech Stack
- Next.js 16
- React 18
- Framer Motion
- Locomotive Scroll
- SCSS modules

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm start
```

## Key Features
- Smooth page transitions and custom cursor
- Hover distortion effects on project cards
- Sticky navigation with mobile menu toggle
- Preloader animation
- Analytics tracking (react-ga)

## Notable Projects
- Chatify — Real-time chat app (Socket.io + Node)
- Track-Mint — Expense tracking with Next.js + MongoDB
- Paper-Trail — Notes app with JWT auth
